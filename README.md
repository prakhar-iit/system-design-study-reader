# System Design Study Reader

An interactive course reader with embedded images and local quizzes, published at the owner's request.

- 41 lessons and 348 embedded images
- 17 local quizzes with 255 original questions
- 32 video thumbnails: 23 official YouTube videos and 9 links to original lesson pages

Reading and quiz progress are stored only in each visitor's browser. Videos require internet access; access-restricted videos open on Hello Interview.

[Open the course reader](https://prakhar-iit.github.io/system-design-study-reader/)
